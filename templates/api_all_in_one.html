🔑 Introduction & Authentication

Base URL

All endpoints are relative to the PDTBuddy host:

https://<pdt-buddy-host>

🔑 API Token Authentication

External tools must send PDTBUDDY_API_TOKEN in one of these ways:

MethodExample
HTTP Header (recommended)X-PDTBuddy-API-Token: your-token
Authorization BearerAuthorization: Bearer your-token
Query parameter?api_token=your-token

Browser sessions (logged-in users) are also accepted — no token needed from the UI.

curl -H "X-PDTBuddy-API-Token: YOUR_TOKEN" https://<host>/api/token/verify
Response format: Most endpoints return JSON. Errors: {"success":false,"message":"..."} or {"ok":false,"error":"..."}.

Common Path Parameters

ParameterMeaningExample

🏗️ Build Report APIs

Full documentation: /build_report/api_docs ↗
POST/api/build_report/runRun report synchronously — one call, one response
▼
⭐ Recommended. Pass filter ID or JQL → get full report back immediately.
FieldRequiredDescription
filter_idrequired*JIRA saved filter ID e.g. "76997"
custom_jqlrequired*Direct JIRA JQL string
buildsrequired*Comma-separated build IDs
targetoptionalTarget name for context
traverseoptionalFollow linked JIRAs (default: true)
orbitoptionalEnrich with Orbit CR data (default: true)

* At least one of filter_id, custom_jql, or builds is required.

curl -s -X POST https://<host>/api/build_report/run \
  -H "Content-Type: application/json" \
  -H "X-PDTBuddy-API-Token: YOUR_TOKEN" \
  -d '{"filter_id": "76997"}'
POST/api/consolidated_reportStart async Build Report job▼

Starts an async consolidated report job. Returns {"ok":true,"job_id":"..."}. Use job_id to poll for results.

GET/api/consolidated_report/result/<job_id>Fetch completed report by job ID▼

Returns 202 while pending, 200 with full report when complete, 500 on failure.

GET/api/consolidated_report/progress/<job_id>SSE stream of job progress events▼

Server-Sent Events stream. Emits JSON progress events until the job completes.

GET/api/consolidated_report/statusPreflight check — verify JIRA credentials
↗ Open
▼

Returns whether JIRA credentials are configured on the server. Use as a health check before submitting jobs.

GET/api/token/verifyVerify API token
↗ Open
▼

Verifies the X-PDTBuddy-API-Token is valid. Returns {"ok":true,"valid":true} or 401.
