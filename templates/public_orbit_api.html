Quick Start Examples

Get all CRs for one target + PL
curl -H "X-PDTBuddy-API-Token: <token>" \
     "http://10.142.213.5/api/public/orbit/crs?target=nord_hgy_ivi_5_1_9_0&pl=SWPDT"
List all available targets
curl -H "X-PDTBuddy-API-Token: <token>" \
     "http://10.142.213.5/api/public/orbit/all-targets"
Get CRs across ALL targets in AUTO BU
curl -H "X-PDTBuddy-API-Token: <token>" \
     "http://10.142.213.5/api/public/orbit/all-crs?bu=AUTO&limit_per_target=100"
Get full orbit detail for one CR
curl -H "X-PDTBuddy-API-Token: <token>" \
     "http://10.142.213.5/api/public/orbit/cr/4477116"
import requests

TOKEN = "your-token-here"
BASE  = "http://10.142.213.5"
HDR   = {"X-PDTBuddy-API-Token": TOKEN}

# ── 1. List all targets ──────────────────────────────────────
r = requests.get(f"{BASE}/api/public/orbit/all-targets", headers=HDR)
targets = r.json()["targets"]
print(f"Found {len(targets)} targets")
for t in targets[:5]:
    print(f"  {t['target']} ({t['bu']})")

# ── 2. Get CRs for one target ────────────────────────────────
r = requests.get(f"{BASE}/api/public/orbit/crs", headers=HDR,
    params={"target": "nord_hgy_ivi_5_1_9_0", "pl": "SWPDT", "limit": 100})
data = r.json()
print(f"\n{data['count']} CRs for {data['target']}")
for cr in data["crs"][:3]:
    print(f"  CR{cr['cr_id']}  hits={cr['cr_occurrence']}  "
          f"priority={cr['orbit']['priority']}  "
          f"tags={cr['orbit']['tags']}")

# ── 3. Get CRs across ALL targets ────────────────────────────
r = requests.get(f"{BASE}/api/public/orbit/all-crs", headers=HDR,
    params={"bu": "AUTO", "limit_per_target": 50})
all_data = r.json()
print(f"\nTotal: {all_data['total_crs']} CRs across {all_data['total_targets']} targets")

# ── 4. Full orbit detail for one CR ──────────────────────────
r = requests.get(f"{BASE}/api/public/orbit/cr/4477116", headers=HDR)
cr = r.json()
print(f"\nCR{cr['cr_number']}: {cr['orbit']['Title']}")
print(f"  Status: {cr['orbit']['Status']}, Priority: {cr['orbit']['Priority']}")
print(f"  Tags: {cr['orbit']['Tags']}")
print(f"  SIRs: {[s['SoftwareImageName'] for s in cr['orbit']['SoftwareImageReleases']]}")

GET /api/public/orbit/crs — One target, optional PL filter

Returns all PDT DB CR data plus full Orbit information (Priority, Assignee, Customer SN/Name, Software Image Releases, CR Tags) for every CR in one target. Optionally filter by product line.

📥 Input Parameters (Query String)
Parameter Type Default Description & Example
targetrequired string — Target name. Use /all-targets to list valid values.
Example: nord_hgy_ivi_5_1_9_0
ploptional string all PLs Product line filter. If omitted, all PLs are returned.
Example: SWPDT
limitoptional integer 500 Max CRs to return. Maximum allowed: 2000.
Example: 100
include_sirsoptional boolean true Include Software Image Releases from Orbit. Set false to skip (faster response).
include_tagsoptional boolean true Include CR tags from Orbit. Set false to skip (faster response).
Example Request
GET /api/public/orbit/crs?target=nord_hgy_ivi_5_1_9_0&pl=SWPDT&limit=50
Host: 10.142.213.5
X-PDTBuddy-API-Token: <token>

GET /api/public/orbit/all-crs — All targets, all PLs

Returns orbit data for CRs across all targets in one call. Optionally filter by Business Unit or product line. Each target's CRs are returned as a separate group.

⚠️ Performance note: This endpoint fetches Orbit data for every CR in every target. It may take 30–120 seconds depending on the number of targets and CRs. Use limit_per_target to control response size. For large datasets, prefer calling /orbit/crs per target in parallel.
📥 Input Parameters (Query String)
ParameterTypeDefaultDescription & Example
buoptional string all BUs Filter by BU key. Example: AUTO, MOBILE, COMPUTE
ploptional string all PLs Filter by product line. Example: SWPDT
limit_per_targetoptional integer 200 Max CRs per target. Maximum: 500. Example: 50
include_sirsoptional boolean true Include Software Image Releases. Set false to skip (faster).
include_tagsoptional boolean true Include CR tags. Set false to skip (faster).
Example Request
GET /api/public/orbit/all-crs?bu=AUTO&pl=SWPDT&limit_per_target=50
X-PDTBuddy-API-Token: <token>

GET /api/public/orbit/cr/<cr_id> — Full orbit record for one CR

Returns the complete Orbit record for a single CR — including Title, Status, Type, Severity, IsCrash, Priority, Reporter, Assignee, Tags, Participants (Area/Subsystem/Functionality), Software Image Releases, Duplicate CRs, Related CRs, and linked sibling CRs from the PDT DB.

📥 Input (Path Parameter)
ParameterTypeDescription & Example
cr_idpath string CR number with or without prefix.
Examples: 4477116 or CR4477116
Example Request
GET /api/public/orbit/cr/4477116
X-PDTBuddy-API-Token: <token>

⚠️

Error Responses

HTTPok fieldWhen it happensExample response body
400 false Missing required parameter {"ok": false, "error": "target parameter is required"}
401 false Not authenticated / bad token {"ok": false, "error": "Authentication required...", "login_required": true}
404 false Target name not found in PDTBuddy {"ok": false, "error": "Target 'xyz' not found"}
500 false Server / Orbit / DB error {"ok": false, "error": "DB connection failed"}

For /all-crs, per-target errors appear in targets_failed[] rather than failing the whole request.
