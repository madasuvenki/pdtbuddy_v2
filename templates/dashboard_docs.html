GET /api/public/orbit/crs Fetch CRs for a target

Returns open/analysis CRs for a given target with area, subsystem, status, and SI image data.

Parameters
ParameterTypeRequiredDescription
targetstringRequiredTarget name e.g. nord_hqx
statusstringOptionalFilter: open, analysis
limitintOptionalMax rows (default 500)
Example Response
{"ok": true, "target": "nord_hqx", "rows": [{"cr": "CR4477116", "cr_title": "...", "cr_status": "Open", "cr_area": "APPS", "cr_age": "45"}], "count": 1}
Try It
GET /api/public/orbit/all-targets List all active targets

Returns all active PDT targets grouped by BU with display names and metadata.

Example Response

Try It
GET /api/public/orbit/cr/<cr_id> Get single CR details

Returns full CR details from Orbit including status, area, subsystem, SIRs, and participants.

Path Parameters
ParameterTypeDescription
cr_idstringCR number e.g. 4477116 or CR4477116
Example Response
{"ok": true, "cr": {"ChangeRequestNumber": "4477116", "Title": "...", "Status": "Open", "Participants": [{"AreaName": "APPS"}]}}
Try It

POST /api/build_report/run Run JIRA build report

Accepts a JIRA filter ID, filter URL, or direct JQL and returns the full JIRA→CR traversal report. Supports both GET (query params) and POST (JSON body). Also accepts ?api_token=<token> for external access.

Request Body (JSON) / Query Params
ParameterTypeDescription
filter_idstringJIRA saved filter ID or full filter URL e.g. 76997
custom_jqlstringDirect JQL string (alternative to filter_id)
buildsarrayList of build IDs to scope the JQL e.g. ["SA8797P.HQX.5.7.7.0-00623"]
traverseboolTraverse JIRA→CR mappings (default true)
orbitboolEnrich CRs with Orbit data (default true)
targetstringTarget name for context e.g. nord_hqx
Example Request Body
{"builds": ["SA8797P.HQX.5.7.7.0-00623"], "filter_id": "76997", "traverse": true, "orbit": true, "target": "nord_hqx"}
Example Response
{"ok": true, "jiras": [{"key": "QSTABILITY-12345", "summary": "...", "cr": "CR4477116"}], "crs": [{"cr": "CR4477116", "cr_title": "...", "cr_status": "Open", "jiras": [...]}], "meta": {"jql": "...", "build_ids": ["SA8797P.HQX.5.7.7.0-00623"], "jira_count": 12, "cr_count": 5}}
Try It (requires login)
GET /api/live_status/targets/<target>/weekly_full Weekly CR/JIRA data

Returns weekly CR rows, JIRA rows, open JIRA rows, build IDs, pie charts, and area matrix for a target.

Query Parameters
ParameterTypeDescription
fromdateStart date YYYY-MM-DD (default: last Monday)
todateEnd date YYYY-MM-DD (default: last Sunday)
Example Response
{"success": true, "from_date": "2026-07-28", "to_date": "2026-08-03", "cr_rows": [...], "jira_rows": [...], "counts": {"total_jiras": 42, "total_crs": 18}}
Try It (requires login)
GET /api/live_status/targets/<target>/open_crs_full Open/Analysis CRs

Returns all open/analysis CRs for a target from the unique_crs table with area, subsystem, functionality, age, and notes.

Query Parameters
ParameterTypeDescription

{"success": true, "rows": [{"cr": "CR4477116", "cr_status": "Open", "cr_area": "APPS", "cr_age": "45", "latest_cr_notes": "..."}], "count": 18}
Try It (requires login)
GET /api/live_status/targets/<target>/mtbf MTBF trend data

Returns MTBF rows from the target's Excel/Axiom data including build ID, hours, crashes, and MTBF value.

Example Response

Try It (requires login)
POST /api/consolidated_report JIRA to CR consolidated report

Runs a JIRA JQL query, traverses JIRA to CR mappings, enriches with Orbit CR data, and returns a hierarchical CR/JIRA report.

Request Body (JSON)
{"builds": ["SA8797P.HQX.5.7.7.0-00623"], "traverse": true, "orbit": true, "target": "nord_hqx", "custom_jql": "filter = 76997 AND summary ~ \"00623\""}
Example Response
{"ok": true, "hierarchical_report": [{"cr": "CR4477116", "cr_title": "...", "jiras": [...]}], "summary": {"total_jiras": 12, "with_cr": 8}}
Try It (requires login)
