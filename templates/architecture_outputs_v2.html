Agentic AI Architecture
PDT Buddy uses a cost-optimized agentic pattern: deterministic Python work first, one optional QGenie/LLM call only when synthesis is needed.
1
Collect with Python toolsFetch DB rows, Orbit data, Jira history, Axiom metrics and cache records using deterministic code.
2
Normalize structured factsBuild compact JSON/table summaries with counts, trends, owners, deltas and evidence references.
3
One optional LLM callQGenie/ChatWise is called only after user action and only for narrative synthesis or unresolved mapping.
4
Cache and reuse outputAnalysis is cached by CR/target/date or input key so repeated reviews do not spend extra tokens.

CR Analysis Agent

  • Collects Orbit, Jira DB, historical trend and cross-BU lookup data before AI synthesis.
  • Provides one-click deep analysis from Open CR Analysis pages.
  • Shows structured data even when QGenie key is not configured.
completecached

WBC Open CR Details

  • Runs TEA API scenario analysis for open CRs.
  • Optionally runs QGenie analysis and saves results to JSON cache.
  • Separates PDT comments from auto-saved TEA/QGenie outputs.
TEAQGenie

Chatbot / Text-to-SQL

  • Uses template and rule-based SQL first for numerically correct answers.
  • LLM fallback is optional and used only when deterministic parsing fails.
  • Supports internal search and QGenie-assisted responses.

API, Access & Deployment Layer
Authentication, role scoping, public API access, modular blueprints and standalone executable packaging.

Authentication & Authorization

  • LDAP login validates Qualcomm users and supports QIPL/SD/CH behavior.
  • Admin users, bypass users, viewer override users and LDAP group scopes control access.
  • Public routes are explicitly exempt where external access is intended.
LDAPRBAC

Public API Surface

  • Auto Gen5 public APIs expose domains, SPs, SP/domain data, search and all-data views.
  • Auto Gen4.5 APIs support SP/HGY SP create, edit, delete, save table and search flows.
  • Public Orbit MTBF APIs reuse Live Status MTBF backend loaders.

Modular Flask Blueprints

  • Modularization continues to reduce legacy monolithic app.py responsibilities.

Packaging & Runtime
