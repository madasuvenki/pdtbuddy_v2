Rev 2.11
Target Delta Studio, CR Overview, Device Summary, AI, Theme & Architecture
Release with weekwise JIRA/unique CR trend and broader platform improvements
Target Delta Studio
QIPLPDT-11029Added Target Delta Studio support for Hawi and Kaanapali AU comparison stats.
Added Generate Weekwise Trend of JIRAs, CRs option in Target Delta Studio.
Weekwise JIRA count includes rows from jiras, openjiras, and closed_jiras tables when available.
Weekwise CR count uses unique mapped CR IDs per week, so duplicate CR mappings are counted once within the same week.
Each target/delta set uses its own selected From JIRA Date and To JIRA Date for weekly trend generation.
Different-year comparisons align by week sequence with month/day labels and without showing year in chart/table labels.
Added CS Week selector to mark selected week as CS, previous weeks as CS-1, and next weeks as CS+1.
Combined weekly graph shows target JIRAs and mapped CRs side-by-side in a single chart.
Added copy-ready Chart and Table buttons for weekwise trend output.
Improved Outlook paste behavior by copying charts with stable white background and consistent colors on HTTP/HTTPS.
Added progress popup while generating weekly trend and target delta results.
CR Overview & Monthly Report
Enhanced CR Overview BU duplicate handling with an Include repeated CRs in BU option.
Added PDT Unique CR support from OverallCrs and exposed PDT Unique CRs as a hero KPI.
Updated CR Overview date filtering to use last-instance date when available so repeated CR activity within the selected period is included.
Updated Monthly Report unique CR date filtering to match CR Overview last-instance behavior.
Added Monthly Report Include NoSIR toggle matching CR Overview behavior.
Device Summary
Improved SP-only Device Summary inventory by enriching active devices through Axiom job playlists and resources.
Added Device Summary target tab with MCN-wise, host-wise, running-device, and quarantine-inferred inventory reporting.
AI, Agentic Flow & Analysis
Added Agentic AI flow design using a cost-optimized pattern: Python tools collect structured data first, then one optional QGenie/LLM call generates the final insight.
Added CR Analysis Agent for one-click deep CR analysis with Orbit/JIRA/history/cross-BU data collection and cached QGenie synthesis.
Added WBC Open CR Details with TEA API scenario details and optional QGenie analysis.
Added QGenie-powered CR summary support for converting Orbit CR data into concise one-line summaries.
Added ChatWise API integration as an alternative LLM-backed summary flow.
Added QGenie Chat support with internal Qualcomm search assistance.
Added text-to-SQL chatbot support for template/rule-based data queries with optional LLM fallback when required.
Maintained per-session QGenie API key handling and model selection through configured QGenie model options.
Defined agentic roadmap items for chatbot SQL agent, Core Deck LLM slide mapping, expanded MCP tools, Live Status Monitor Agent, and Report Narrative Agent.
UI, MTBF & Architecture
Improved UI theme with full dark-mode coverage, soft navy dark colors, and more vibrant light-mode backgrounds.
Fixed Compute MTBF JSON routing so non-Glymur Compute targets use target-specific JSON folders.
Added application composition registry for centralized blueprint registration.
Added modular utility modules for user activity, cache utilities, CR utilities, authentication routes, navigation routes, and HWPDT routes.
Maintained Windows PyInstaller packaging support for standalone PDT Buddy executable distribution.
