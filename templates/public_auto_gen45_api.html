Public read endpoints
HQX
GET{{ base }}/public/auto-gen45/api/sps
GET{{ base }}/public/auto-gen45/api/sp/8620?last_n=5&summary=true
HGY
GET{{ base }}/public/auto-gen45/api/hgy/sps
GET{{ base }}/public/auto-gen45/api/hgy/sp/8620?last_n=5&summary=true

last_n — latest N rows (0 = all) • summary — include summary block (default true). Editor-only POST endpoints also exist for create/add/edit/delete/save table operations.

MTBF column semantics: total/system+process MTBF is published as mtbf. Overall MTBF is published as single JSON key overallmtbf and shown separately in the summary table.
