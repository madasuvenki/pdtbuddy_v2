Endpoints

HQX — Read-only (no login required)

List all HQX SPs

GET{{ base }}/public/auto-gen45/api/sps

Get HQX rows for an SP

GET{{ base }}/public/auto-gen45/api/sp/8620?last_n=5&summary=true

last_n — latest N rows (0 = all) • summary — include summary block (default true)

HGY — Read-only (no login required)

List all HGY SPs

GET{{ base }}/public/auto-gen45/api/hgy/sps

Get HGY rows for an SP

GET{{ base }}/public/auto-gen45/api/hgy/sp/8620?last_n=5&summary=true

last_n — latest N rows (0 = all) • summary — include summary block (default true)
