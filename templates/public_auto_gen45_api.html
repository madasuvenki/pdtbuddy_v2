API 1: List available SPs

GET {{ base }}/public/auto-gen45/api/sps
curl "{{ base }}/public/auto-gen45/api/sps"
{
  "ok": true,
  "message": "Available SPs fetched successfully.",
  "available_sps": [
    {"sp": "8620", "program": "8620 (ADAS)", "domain": "ADAS", "row_count": 97}
  ],
  "count": 5
}

API 2: Get one SP table

GET {{ base }}/public/auto-gen45/api/sp/8620?last_n=0&summary=true
ParamRequiredMeaning
sp pathYesSP number or program text. Example: 8620, 8775.
last_nNo0 or omitted returns full table. 5 returns latest 5 rows.
summaryNotrue default includes summary metrics. Use false to skip.
 
curl "{{ base }}/public/auto-gen45/api/sp/8620?last_n=5&summary=true"

API 3: Search within one SP

GET {{ base }}/public/auto-gen45/api/search?sp=8620&q=Snapdragon&limit=10
ParamRequiredMeaning
spYesSP to search inside.
q or queryNoText to search across row values. Empty query returns rows up to limit.
limitNoMax matched rows. Default 50.
 
{
  "ok": true,
  "message": "Search completed for SP '8620'.",
  "requested_sp": "8620",
  "resolved_program": "8620 (ADAS)",
  "query": "Snapdragon",
  "matches": [ ... ],
  "match_count": 10,
  "truncated": true
}

Response shape and errors

Successful SP response

{
  "ok": true,
  "message": "SP '8620' data fetched successfully.",
  "requested_sp": "8620",
  "resolved_program": "8620 (ADAS)",
  "rows": [
    {"date": "2026-01-01", "hours": 120, "crashes": 1, "mtbf": 120}
  ],
  "row_count": 1,
  "summary": {
    "latest_date": "2026-01-01",
    "latest_build": "...",
    "latest_mtbf": 120,
    "total_hours": 120,
    "total_crashes": 1
  }
}

SP not available

{
  "ok": false,
  "message": "Requested SP '9999' is not available in Auto Gen4.5 data.",
  "requested_sp": "9999",
  "available_sps": [ ... ],
  "rows": [],
  "row_count": 0
}
If a tool asks for an invalid SP, call /api/sps first and let the user choose from the returned available_sps.

External tool / MCP help

For normal HTTP tools, use the REST APIs above. If an external tool supports MCP SSE, it can connect to:

http://{{ public_host }}:8775/sse

Recommended MCP call:

{
  "tool": "get_sp_info",
  "arguments": {
    "sp": "8620",
    "last_n": 0,
    "include_summary": true
  }
}
