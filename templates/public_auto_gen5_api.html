Mobile BU Public API
Mobile MTBF API — Same pattern as IoT/XR
Mobile targets use the same generic MTBF API. Pass ?bu=MOBILE to filter Mobile targets.
GET{{ base }}/public/mtbf/api/targets?bu=MOBILE
List all Mobile targets with MTBF status
GET{{ base }}/public/mtbf/api/targets?bu=MOBILE&mtbf_only=1&include_sps=1
Mobile targets with MTBF + SP list
GET{{ base }}/public/mtbf/<target>/MTBF
Base MTBF rows for a Mobile target
GET{{ base }}/public/mtbf/<target>/sp/<cpl>/MTBF?domain=ADAS
SP-scoped MTBF rows for a Mobile target
GET{{ base }}/public/mtbf/api/all?bu=MOBILE&last_n=5&include_sps=1
All Mobile targets in one call
Params: ?bu=MOBILE   ?last_n=5   ?summary=1   ?include_sps=1   ?domain=ADAS

Note: Mobile targets are auto-discovered from the MOBILE BU config. When a new Mobile target is added to the BU, it automatically appears in all endpoints.
Orbit CR Public API Full Docs
CR data from Orbit — requires API token or active session. Returns open CRs, CR details, and target lists.
GET{{ base }}/api/public/orbit/all-targets
List all available targets with CR data
GET{{ base }}/api/public/orbit/crs?target=<target>&pl=<pl>
All open CRs for a target/PL — CR ID, title, status, area, assignee, age
GET{{ base }}/api/public/orbit/all-crs
All CRs across all targets (optional ?target= filter)
GET{{ base }}/api/public/orbit/cr/<cr_id>
Full details for a single CR including JIRA mappings
Params: ?target=<target>   ?pl=<pl>
Auth: Pass ?api_token=<token> or use an active browser session.
