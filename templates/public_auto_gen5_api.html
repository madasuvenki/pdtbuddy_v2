★ How to get SP domain MTBF data (HQX 5.7.7.0 & HGY 5.1.7.0)
Endpoint: /api/sp/<cpl>/domain/<domain>?target=<target>
• HQX SP 5.7.7.0: target=nord_hqx&sp=5.7.7.0 — domains: ADAS, FLEX, IVI
• HGY SP 5.1.7.0: target=nord_hgy&sp=5.1.7.0 — domains: ADAS, CSP, FLEX, NONSAFE-IVI, SAFE-IVI
• HGY SP 5.1.9.0: target=nord_hgy&sp=5.1.9.0 — domains: ADAS, FLEX, NONSAFE-IVI, SAFE-IVI
• CPL (5.7.7.0) and compact key (5770) both work • Add ?last_n=5 to limit rows
