Endpoints

API 1 — List domains for a target

GET{{ base }}/public/auto-gen5/api/domains?target=nord_hqx

API 2 — Get rows for a domain

GET{{ base }}/public/auto-gen5/api/domain/ADAS?target=nord_hqx&last_n=5&summary=true

target — nord_hqx or nord_hgy • last_n — latest N rows (0=all) • summary — include summary (default true)
