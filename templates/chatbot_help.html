PDT Buddy — Quick Help

Use PDT Buddy like a search assistant. Ask in plain English, and it will return a simple answer at user level. You do not need to know table names, joins, or internal relationships.

How to search

Search by CR

  • Type a CR number directly, like CR123456
  • Ask for a specific CR: show CR123456 details
  • Ask for related CRs: related CRs for CR123456

Search by status or keyword

  • show open CRs
  • show built CRs
  • find crash CRs
  • show CRs for modem with status open

What output you will see

  • Short summary — a plain-English response first.
  • List or table — if multiple results are found, PDT Buddy may show a compact table or list.
  • Counts — for questions like “how many”, you will get a count with a short explanation.
  • Details — for a single CR, you will get the main information only, not internal technical metadata.

Example: “I found 6 open CRs for modem. Here are the top results.”

Common examples

  • show me CRs for camera
  • how many built CRs do we have?
  • find crash CRs in infotainment
  • show details for CR123456
  • what are the related CRs for CR123456?

JiraQuery / filter report

To run a JiraQuery filter report, paste the full command into PDT Buddy. The command must include jiraquery=; PDT Buddy will start the report and show progress.

  • Use filter=<id> when you already have a saved JIRA filter ID.
  • Use JiraQueryLimit to control the maximum number of rows returned.
  • Use $SkipHwPdtQStabilityCheck when you want to skip the HW PDT QStability check.

Sample:

jiraquery="filter=115827" $processCRinfo JiraQueryLimit=2000 $SkipHwPdtQStabilityCheck

Tips for best results

  • Be specific if you know the target, team, or CR number.
  • Use simple phrases like open, built, crash, related, or count.
  • If the chatbot asks for confirmation, choose No if you want a normal answer instead of a workflow action.

What this page does not show

  • No table interlink details
