Quick guidance

Chatbot examples

Use simple natural-language questions. Include a target, CR number, or status when available for more accurate results.

  • show open CRs for modem
  • show details for CR123456
  • how many built CRs do we have?
  • find crash CRs in infotainment

Before contacting support

Please include enough information for the team to investigate quickly.

  • Page URL or target name
  • Screenshot of the issue
  • Error message and time observed
  • Expected result versus actual result
