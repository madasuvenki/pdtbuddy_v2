Hi All,

PDT Buddy has evolved from the initial dashboard release to v2.11, bringing multiple dashboard, reporting, CR/JIRA, Live Status, MTBF, Device Summary, API, and automation enhancements.

Platform Capabilities Available in Current Codebase
  • Supports Qualcomm LDAP authentication with region-aware Orbit endpoint routing.
  • Supports role-based access through admin users, bypass users, LDAP groups, and viewer scope controls.
  • Supports multi-BU dashboard routing with target-specific MySQL schema mapping.
  • Supports Live Status publishing, editing, public viewing, and target-specific status pages.
  • Supports saved JQL tabs and saved JQL report generation for Live Status views.
  • Supports public Auto Gen5 APIs for domain, SP, and all-data views without login.
  • Supports public Auto Gen4.5 APIs for SP, HGY SP, search, create, edit, delete, and save-table flows.
  • Supports public Orbit MTBF APIs for external consumers.
  • Supports Device Summary APIs for upload, sheet selection, config save, refresh, devices list, add, edit, delete, restore, and inventory summary.
  • Supports QGenie and ChatWise based AI summary flows with model selection and per-session API key handling.
  • Supports optional MCP MTBF server for external AI/tool access to MTBF trend data.
  • Supports filesystem result caching with signed result tokens for generated reports.
  • Supports Waitress WSGI server deployment for production-style Windows executable hosting.
